# Skills I chose

Searched skills.sh on 2026-11-08 with `npx skills find` for: email marketing, email sequence, campaign plan, resend. Nothing was installed.

## Use these

1. **anthropics/knowledge-work-plugins** (`campaign-plan`, `email-sequence`)
   Published by Anthropic, an official publisher, and the repo has about 35,000 GitHub stars. It was pushed to as recently as yesterday. It covers both planning a campaign and writing the email sequence, and it is the plugin this studio installs in the next step.

2. **resend/resend-skills** (`resend`)
   Published by Resend itself, the company that makes the email service we will connect to, so it is the authority on how to send through it. It has about 211 stars, which is small, but the owner is the official organization and it has about 24,000 installs. Also note `resend/email-best-practices` as a follow-up.

## Avoid these

1. **caffeinelabs/skills@extension-email-marketing** (about 30,500 installs, the top "email marketing" result)
   The repo has 2 GitHub stars. Thirty thousand installs against 2 stars is a mismatch. Install counts can be faked, and nothing else vouches for this one.

2. **samber/dev-event-organizer-skills@event-attendee-email-sequences** (about 6,600 installs)
   The repo has 4 stars, sits under a personal account, and was only created in September 2026. It is built for event attendees, not product launches, so it is the wrong tool even if the numbers were real.

## How I decided

1. **Who made it?** Prefer official publishers (Anthropic, Resend) or well-known maintainers over unknown accounts.
2. **Do the stars match the installs?** A big install count on a repo with a handful of stars is a warning sign. Install counts alone prove nothing.
3. **Is it alive and does it fit?** Check the repo was updated recently, and that the skill does the job I need (a launch campaign) rather than a nearby one.
